# Instructions for Codex

## Scope
Build LAST SIGNAL from this pack. No real money, no mainnet deployment, no token purchases, no paid subscriptions. Do not commit private keys, provider keys, wallet signatures, personal information, or full environment files. Do not overwrite earlier projects. No unsolicited outbound messages.

## Working method
Inspect the repository and existing instructions first. Use the existing package manager if appropriate. Otherwise use npm workspaces and commit the lockfile. Choose supported dependency versions after inspecting current official documentation. Record actual versions and commands. Use TypeScript strict mode. Build small vertical slices and run meaningful checks at each stage. Maintain README.md, docs/DECISIONS.md, docs/STATUS.md, and docs/FACTS.md.

Start with the visual proof and a local bot match. Do not spend the entire schedule building wallet plumbing before a battlefield exists. Never represent an offline screenshot as proof of multiplayer or chain integration.

## Prose
Use straightforward language. Avoid hyphen or dash characters in prose where practical, matching the owner's earlier project preference. Language syntax, package identifiers, URLs, and command options may use them.

## Visual honesty
No GTA 6 quality promise. No copied commercial models, audio, logos, or screenshots. Asset provenance and licenses are required. Temporary assets must be marked in the asset register. Use procedural geometry and original materials as the free baseline.

## Stop conditions
Ask a focused question only for missing credentials, ambiguous ownership, unavailable external deployment access, or a product change with major consequences. Continue independent local work while external access is blocked. A failed faucet does not block the local mock chain or practice mode. Do not bypass any restriction or invent a transaction hash.

## Completion reporting
Report what works, what was actually tested, remaining limitations, exact launch commands, and available URLs. Distinguish local practice, local blockchain, public testnet, and deployed multiplayer. No simulated wallet balance may masquerade as a chain read.
